# Samsung Controller

- `app/`: app SwiftUI (cópia do app TCL, só com mudanças de configuração; ver `app/README.md`).
- `sidecar/`: serviço Python (porta 8766), a implementar.
- `docs/CONTRATO-API.md`: contrato HTTP entre app e sidecar.
- `docs/superpowers/specs/`: design.
